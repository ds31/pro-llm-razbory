# data

Только синтетика. Вымышленная сеть: 60 товаров — обувь, одежда, товары для дома.

- `catalog_erp.csv` — что знает учётная система: все поля заполнены;
- `catalog.csv` — опубликованные карточки (сайт, фид): часть полей потерялась при выгрузке, у части GTIN ошибка контрольной цифры;
- `make_catalog.py` — генератор с фиксированным seed: `uv run python data/make_catalog.py`. Тест проверяет, что файлы в git совпадают с выводом генератора.
