# Прочитать публичный бенчмарк

Ответить по пунктам, со ссылкой на первоисточник (статья или страница бенчмарка), а не на пересказ:

1. **Задача.** Что делает модель в бенчмарке: один ответ, код, браузер, SQL, диалог с инструментами? Совпадает ли с задачей вашего агента?
2. **Данные.** Чьи данные и насколько они похожи на ваши: открытые учебные базы или грязная учётная система с правилами компании?
3. **Каркас.** Модель мерили с каким системным промптом, инструментами и лимитом шагов? Одинаков ли каркас у всех строк рейтинга?
4. **Утечка.** Тест-сет открыт? Есть ли данные о запоминании (модель решает задачу, не видя её целиком)? Есть ли закрытая часть?
5. **Метрика.** Доля решённых с какой попытки (pass@k или pass^k)? Есть ли цена и время на задачу?
6. **Перенос.** Что из этого переносится на ваш агент: обычно — только шорт-лист моделей.

Итог — шорт-лист из 3–5 моделей и команда своего прогона:
`uv run razbor04 bench --models <шорт-лист> --only Q07,Q23` (пробно), затем полный прогон по `checklist.md`.
