# Добавить модель

1. Найти модель в прайсе OpenRouter (https://openrouter.ai/models) или у провайдера: точное имя (`vendor/model`), цена входа и выхода за 1M токенов.
2. Добавить строку в `PRICES` в `src/razbor04/prices.py`; если дата прайса другая — поправить дату в комментарии модуля и `PRICE_SOURCE` в `cli.py`.
3. Дописать имя модели в список `test_task_models_are_priced` в `tests/test_prices.py`; `uv run pytest -q` — зелёный.
4. Пробный прогон на двух вопросах, только по просьбе человека: `uv run razbor04 bench --models <имя> --only Q07,Q23 --max-usd 0.5`.
5. Проверить в выводе: нет ошибок API (`error: …`), ответ — число. Если модель не принимает `output_config` — запустить с `--effort none` и записать это в README.
6. Сравнить колонки «$ за ответ, прайс» и «списано» в `eval/out/report.html`: расхождение больше чем вдвое — запрос ушёл провайдеру дороже прайса; отметить это рядом с ценой.
7. Полный прогон — по просьбе человека и с `--max-usd`.
