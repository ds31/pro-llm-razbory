# CLAUDE.md — пакет 04 «Бенчмарк на своих данных»

Отвечай по-русски.

## Что это

Скрипт сравнения моделей для агента-аналитика. Берёт eval пакета 01 (30 вопросов о синтетической розничной сети, варианты A — сырые таблицы и B — слой метрик) и прогоняет его на списке моделей через Messages API: точность, цена ответа по прайсу и по списанию, время, шаги, $ за верный ответ, ошибки API отдельно от неверных ответов. Агент, инструменты, вопросы и эталоны — из пакета 01 без изменений; меняется только имя модели.

## Команды

- тесты: `uv run pytest -q` (в API не ходят);
- цены: `uv run razbor04 models`;
- база: `uv run razbor04 data` → `data/retail.duckdb`;
- прогон: `uv run razbor04 bench --models a,b [--variants A,B] [--only Q07,Q23] [--limit N] [--run 2] [--repeat N] [--effort medium|none] [--max-usd 1] [--offline]`;
- отчёт по всем прогонам в `eval/out/runs/`: `uv run razbor04 report`; из прогона автора: `uv run razbor04 report --from eval/reference-run.json`;
- всё сразу: `uv run razbor04 all` (четыре модели по умолчанию);
- ключ: `OPENROUTER_API_KEY` (пакет сам пойдёт в `https://openrouter.ai/api`) или `ANTHROPIC_BASE_URL` + `ANTHROPIC_AUTH_TOKEN`, или `ANTHROPIC_API_KEY` для моделей Claude напрямую.

## Правила

1. Только синтетические данные; реальные базы, выгрузки и названия компаний не подключать.
2. Все модели прогона — в одинаковых условиях: тот же агент, промпт, инструменты, лимит шагов и `effort`. Меняется только модель.
3. Новая модель — с ценой и датой прайса (скилл `add-model`); без цены платный прогон не стартует.
4. Ошибка API — не неверный ответ: считается отдельно, в «$ за верный ответ» её расходы входят.
5. Платный прогон — только по просьбе человека, сначала `--only` на одном-двух вопросах и всегда с `--max-usd`.
6. Ключ API — только из окружения; `.env` не читать и не коммитить.
