# eval

- Вопросы, эталоны и слой метрик — из пакета 01 (`../01-agent-vret-v-cifrah/eval/questions.yaml`, `metrics.yaml`): 30 вопросов, по шесть на ловушку `none`, `dup_join`, `anomaly`, `open_month`, `definition`; эталон — живой `check_sql`, допуск ±0,5 %.
- Прогон — команда из `README.md` пакета; ответы каждой модели и прогона пишутся сразу в `out/runs/<модель>.r<прогон>.jsonl` вместе с трассами; сводка — `out/summary.json`, отчёт — `out/report.html` (в git не попадают).
- Критерий «прошёл» для модели — как в пакете 01: не меньше 27 из 30 на варианте, который пойдёт в прод; ошибки API считаются отдельно и прогон с ними повторяют.
- `reference-run.json` — прогон автора 21.10.2026: шесть моделей, 840 ответов без трасс — цифры статьи. Отчёт из него: `uv run razbor04 report --from eval/reference-run.json`.
