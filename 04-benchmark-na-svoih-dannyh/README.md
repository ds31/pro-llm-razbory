# 04 · Какую модель брать агенту-аналитику — и почему публичный бенчмарк на это не ответит?

Рубрика: Как читать AI. Статья: https://pro-llm.ru/blog/kakuyu-model-vybrat-agentu-benchmark-na-svoih-dannyh.html

Скрипт сравнения моделей на своём eval. Агент-аналитик из [пакета 01](../01-agent-vret-v-cifrah) отвечает на 30 вопросов о синтетической розничной сети в двух вариантах — по сырым таблицам (A) и через слой метрик (B), — а скрипт меняет под ним только модель. На выходе — верные ответы из 30 с разбивкой по ловушкам, $ за ответ по прайсу и по факту списания, секунды и шаги цикла на ответ, $ за верный ответ, ошибки API отдельно от неверных ответов, HTML-отчёт с картой «точность × $ за ответ». К пакету — `checklist.md`: что проверить перед выбором модели.

## Результат прогона автора

21.10.2026, OpenRouter, `effort: medium` у всех моделей. Opus и Sonnet — один прогон, остальные — три (в скобках — счёт каждого). $ — списано OpenRouter (`usage.cost`). Все 840 ответов — в `eval/reference-run.json`.

| Модель | A — сырые таблицы | B — слой метрик | $ за ответ, A / B | $ за верный ответ, B | Секунд на ответ, A / B |
|---|---|---|---|---|---|
| `anthropic/claude-opus-5.5` | 26 | **30** | 0,083 / 0,033 | 0,033 | 21,8 / 8,5 |
| `anthropic/claude-sonnet-5.5` | 24 | **30** | 0,026 / 0,016 | 0,016 | 9,9 / 4,4 |
| `anthropic/claude-haiku-5.5` | 25 (27; 24; 24) | **30** (30; 30; 30) | 0,0023 / 0,0010 | 0,0010 | 10,8 / 4,6 |
| `deepseek/deepseek-v4.1-flash` | 15,7 (16; 15; 16) | **30** (30; 30; 30) | 0,0010 / 0,0007 | 0,0007 | 7,6 / 4,8 |
| `z-ai/glm-5.3` | 12,7 (13; 12; 13) | **29** (29; 29; 29) | 0,0010 / 0,0010 | 0,0011 | 4,8 / 3,4 |
| `openai/gpt-5.6-luna` | 13,3 (12; 14; 14) | **30** (30; 30; 30) | 0,0009 / 0,0005 | 0,0005 | 8,9 / 7,8 |

Что показал прогон:

- **На слое метрик разрыв между моделями исчез:** пять моделей — 30 из 30, `glm-5.3` — 29 (в двух прогонах вписал в поле числа сумму возвратов вместо доли, в одном исчерпал 12 шагов). На сырых таблицах — от 12,7 до 26.
- **Платформа дешевле смены модели:** Opus на сырых таблицах — 26 из 30, $0,083 и 21,8 с на ответ; Haiku через слой метрик — 30 из 30, $0,001 и 4,6 с.
- **Дешёвые модели без платформы пишут наивный запрос:** аномальные строки — 0 из 6 у DeepSeek, GLM и GPT-5.6-luna во всех прогонах; на вопросе про бренд DeepSeek и GLM во всех прогонах, а GPT-5.6-luna в одном из трёх дали одно и то же неверное число — ровно то, что даёт `trap_sql` с join по справочнику с дублями.
- **Разброс между прогонами — только на сырых таблицах:** Haiku A — 27, 24, 24; на слое метрик у всех трёх прогонов одинаковый счёт.
- **Прайс ≠ счёт:** у DeepSeek и GLM списано в 1,6–1,8 раза больше, чем по прайсу на 21.10.2026; у GPT-5.6-luna на варианте B — в 2,4 раза меньше (вход из кэша провайдера). У моделей Claude совпадает.

Весь прогон автора — 840 ответов — списано $5,50.

## Запуск одной командой

```bash
uv run razbor04 all
```

Нужны [uv](https://docs.astral.sh/uv/) и ключ: `OPENROUTER_API_KEY` (пакет сам пойдёт в `https://openrouter.ai/api`) или `ANTHROPIC_API_KEY` для моделей Claude напрямую. `all` гоняет четыре модели (Opus, Sonnet, Haiku, DeepSeek) по 60 ответов — около $4,9 по ценам 21.10.2026, Opus из них — около $3,5. Отчёт — `eval/out/report.html`.

Без ключа и бесплатно:

```bash
uv run razbor04 report --from eval/reference-run.json   # отчёт прогона автора
uv run razbor04 all --offline --limit 3                 # проверка конвейера эталонными ответами (это не агент)
```

Пробный платный прогон на двух вопросах с потолком расходов:

```bash
uv run razbor04 bench --models anthropic/claude-haiku-5.5,deepseek/deepseek-v4.1-flash --only Q07,Q23 --max-usd 0.2
```

Своя модель: `uv run razbor04 models` — список с ценами; новая — строкой в `src/razbor04/prices.py` (скилл `add-model`). Второй прогон для разброса: `--run 2` или `--repeat 3`. Без параметра `output_config.effort`: `--effort none`.

## Как сравнить модели на своём агенте

1. Собрать eval на 30 вопросов с эталонами — как в пакете 01 (скилл `add-eval-question` там).
2. Заменить в `run_bench` агента и инструменты своими; счётчик `MeteredClient` оборачивает любой клиент Messages API.
3. Внести модели шорт-листа с ценами (`add-model`), пройти `checklist.md`.
4. Прогнать: пробно на двух вопросах, затем полностью с `--max-usd`; дешёвые модели — 2–3 раза.
