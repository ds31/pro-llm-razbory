# eval

- `questions.yaml` — 30 вопросов: по шесть на теги `none`, `dup_join`, `anomaly`, `open_month`, `definition`. Формат описан в шапке файла.
- Эталон — живой запрос `check_sql` по сырым данным с правилами компании; число не хранится. «Последний месяц» — последний месяц со снимком остатков.
- Верно — если ответ отличается от эталона не больше чем на `tolerance_pct` (по умолчанию ±0,5 %; номера и счёт — точно).
- Критерий «прошёл»: агент верен на всех вопросах во всех трёх повторах (pass^3 = 100 %); правка проходит, если `compare` вернул код 0.
- `reference-run.json` — прогон автора: прогоны агента (ответы и трассы), записанные числа на 10.10, вердикты судей, сводка — цифры статьи. Пересчёт без ключа: `uv run razbor03 all --offline`.
- `out/` — ваши прогоны, отчёт `out/report.html`, в git не попадают.
