# data

Базы DuckDB собираются командой `uv run razbor03 data` и в git не попадают:

- `base.duckdb` — синтетическая розничная сеть пакета 01, выгрузка 10.10.2026;
- `reload.duckdb` — та же база после дозагрузки по 10.11.2026: продажи 11.10–10.11 и остатки на 31.10; история не меняется;
- `no-anomaly-rule.duckdb` — сырые данные base, витрины собраны без правила «|qty| >= 1000 — ошибка сканера».

Данные только синтетические.
