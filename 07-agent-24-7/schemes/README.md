# schemes

Исходники схем статьи: `scheme.py` — копия `web/tools/scheme.py` сайта pro-llm.ru (стиль), `schemes_razbor_07.py` — три схемы разбора: две схемы запуска агента и их итог, шаблон деплоя и где он ломается, сбои по одному. Цифры — из `eval/reference-run.json`. Перерисовать в эту папку из корня пакета:

```bash
SCHEMES_OUT=schemes python3 schemes/schemes_razbor_07.py
```
