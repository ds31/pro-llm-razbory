# CLAUDE.md — пакет 07 «Агент 24/7»

Отвечай по-русски.

## Что это

Эксперимент без LLM: «ночь» из 1 000 вопросов магазинов вымышленной розничной сети проходит через агента (три вызова модели, запрос в витрину, письмо магазину) в трёх конфигурациях — наивной (агент синхронно в обработчике API, SDK по умолчанию), очереди с ретраями без идемпотентности и прод (очередь с арендой и heartbeat, ретраи с backoff и джиттером, dead-letter, ключи идемпотентности на постановке и на письме, таймауты, трасса). Сбои — по профилю фейковой модели и сценария ночи; часы виртуальные, всё детерминированно по seed. Меряется: потерянные задачи, дубли писем, dead-letter, p50/p95 до ответа, полнота трассы, вызовы модели. Тот же агент и та же очередь работают в docker compose (`deploy/`).

## Команды

- тесты: `uv run pytest -q` (около минуты, Docker и API не нужны);
- всё сразу: `uv run razbor07 all` (ночь, сбои по одному, 100 ночей, трасса, отчёт `eval/out/report.html`); быстрее — `-n 10`;
- одна ночь: `uv run razbor07 night --profile <профиль> [--config naive|queue|prod] [--seed N]`; профили — `PROFILES` в `src/razbor07/experiment.py`;
- трасса задачи: `uv run razbor07 trace --config prod [--task store-26/q-0306]`;
- шаблон деплоя: `docker compose -f deploy/docker-compose.yml config --quiet`; хаос-тест — `./deploy/chaos.sh` (нужен Docker).

## Устройство

| Путь | Что |
|---|---|
| `src/razbor07/agent.py` | агент — генератор операций `Call`/`Tool`/`Send`/`Sleep`; конфигурации `NAIVE`, `QUEUE`, `PROD` |
| `src/razbor07/queue.py` | очередь SQLite: `enqueue` с ключом, `claim` с арендой и подбором истёкших, `heartbeat`, `ack`, `fail` с backoff и dead-letter |

## Правила

1. Только синтетические данные; реальные базы, журналы и названия компаний не подключать.
2. Агент один для симулятора и для живого режима: логику меняют в `agent.py`, а не в `sim.py` или `worker.py`.
3. Новый сбой — параметр в `Faults` или `Night`, профиль в `PROFILES` и тест: прод не теряет и не дублирует, трасса полная.
4. Новый необратимый шаг агента — операция `Send` (или своя) с ключом идемпотентности от ключа задачи и тест на повтор после этого шага.
5. Метрики считаются только из событий журнала и шлюза; поправить цифру руками нельзя — только сценарий и прогон.
6. Ключ API — только из окружения; `.env` не читать и не коммитить. Живой LLM пакету не нужен.
