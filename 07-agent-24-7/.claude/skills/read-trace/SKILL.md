# Трасса задачи

1. Собрать события задачи: в прогоне — `uv run razbor07 trace --config prod --task <ключ>`; в docker compose — `docker compose logs worker api | grep '"task": "<ключ>"'`.
2. Разложить по попыткам (`exec`): `claimed` → вызовы `call` (шаг, исход, мс, токены, `cost_usd`) → `send` или `send_deduped` → чем кончилась попытка: `done`, `retry_scheduled` (ошибка и задержка), `dead`, `lease_expired` (воркер убит или завис).
3. Попытка без конечного события — слепая зона: процесс убит, а аренды нет (наивная схема). В проде такого быть не должно.
4. Дубль письма: найти два `send` без ключа — какая попытка отправила второе и почему она вообще началась (потерянный ответ клиенту без ключа задачи или повтор после письма без ключа письма).
5. Dead-letter: причина — последнее `error`. 400 / битый вход — исправить данные; 429 / 529 / таймаут — исчерпаны попытки, проверить лимит и воркеры. После исправления — `Queue.requeue_dead(id, now)`; повторная отправка письма по ключу не уйдёт.
6. Цена задачи — сумма `cost_usd` по всем попыткам; доля повторов — вызовы сверх трёх.
