# 06 · Как довести AI-агента от первого разговора до приёмки — и где проект застревает?

Рубрика: FDE в поле. Статья: https://pro-llm.ru/blog/kak-dovesti-ai-agenta-do-priemki.html

Путь Forward Deployed Engineer на одном файле. Discovery записывается в `discovery.yaml`: вопрос руководства дословно, решение, метрика, источник, владелец числа и подписанный эталон. Скрипт проверяет, готов ли файл к приёмке, и собирает из него кейсы приёмки: базовый на каждый вопрос и по пробе на каждую проблему данных и каждое определение, которое легко перепутать. Дальше ворота G1–G5 выносят вердикт по вариантам прототипа. Сквозной пример — синтетическая розничная сеть [пакета 01](../01-agent-vret-v-cifrah) и вопрос генерального директора «Какая выручка за сентябрь по магазинам?».

## Результат прогона автора

Без LLM: ответы агента — записанный прогон пакета 01 (`claude-sonnet-5.5`, 19.10.2026). Все цифры — в `eval/reference-run.json`.

| Шаг | Результат |
|---|---|
| Discovery после первой встречи (`discovery-day1.yaml`) | 3 вопроса, не готов: 24 пробела — нет решений, определений, периодов, владельцев и эталонов |
| Discovery после недели (`discovery.yaml`) | готов к приёмке; дубли карточек товаров не задевают ни один вопрос — в приёмку не входят |
| Кейсы приёмки (`acceptance.yaml`) | 7 кейсов: M1 — 4, M2 — 2, M3 — 1; базовый кейс M1 — таблица на 12 магазинов |

| Ворота | A — SQL по сырым таблицам | B — слой метрик |
|---|---|---|
| G1 кейсы полные | пройдены | пройдены |
| G2 эталоны считаются | пройдены | пройдены |
| G3 слой даёт эталон | не применимо | пройдены, 7 из 7 кейсов и 12 из 12 магазинов |
| G4 агент в допуске ±0,5 % | **не пройдены**: 3 ошибки из 6 ответов | 6 из 6, **ждёт прогона**: 12 вопросов «по магазинам» |
| G5 цена и время ответа | $0,0185 · 8,0 с | $0,0158 · 4,8 с |
| **Вердикт** | **не принят** | **ждёт прогона** |

Ошибки A: магазин №2 за август — 19 908 486,09 вместо 358 641,27 (восемь строк-ошибок сканера), регион «Восток» за последний месяц — 392 589,91 вместо 1 065 715,28 (десять дней незакрытого октября), доля возвратов за третий квартал — 0,48 % вместо 1,17 % (те же строки-ошибки августа раздули валовые продажи). Все три числа A — ровно те же запросы без правил компании (`profile` в сводке). В сентябре строк-ошибок нет: прототип, проверенный только на сентябре по магазинам, сдался бы.

B ответил верно на все шесть записанных вопросов, но сам вопрос руководства — выручку каждого из 12 магазинов — в прогоне пакета 01 не задавали. Пакет выгружает эти 12 вопросов для прогона.

## Запуск одной командой

```bash
uv run razbor06 all
```

Нужен [uv](https://docs.astral.sh/uv/). Ключ API не нужен: база строится генератором пакета 01, ответы агента берутся из его записанного прогона. Отчёт — `eval/out/report.md`, сводка — `eval/out/summary.json`.

Закрыть «ждёт прогона» для B (платно, ключ `ANTHROPIC_API_KEY` в окружении; по средней цене ответа B в пакете 01 — около $0,19 за 12 вопросов):

```bash
uv run razbor01 eval --root eval/out/agent-root-B --variants B
uv run razbor06 accept --variants B --results eval/out/agent-root-B/eval/out/results.jsonl
```

Через OpenRouter — как в пакете 01: `ANTHROPIC_BASE_URL=https://openrouter.ai/api`, ключ в `ANTHROPIC_AUTH_TOKEN`, `--model anthropic/claude-sonnet-5.5`.

## Как применить у себя

1. Скопировать `templates/discovery.yaml`, провести интервью по `templates/interview.md`, проверить: `uv run razbor06 check discovery.yaml --no-catalog` (без флага метрики сверяются с каталогом пакета 01).
2. Пока `check` показывает пробелы — это список вопросов к людям, а не повод начинать прототип.
3. `uv run razbor06 scaffold discovery.yaml -o acceptance.yaml` — согласовать кейсы с владельцами чисел.
4. Заполнить `templates/prototype-spec.md` и `prototype.yaml`: пороги до первой строки кода.
5. Подключить свою базу и слой метрик вместо пакета 01 (`accept.py`: `golden_value`, `layer_value`) и прогнать агента на кейсах.

## Тесты

```bash
uv run pytest -q
```

Тесты в API не ходят; конвейер «экспорт → `razbor01 eval` → `accept`» проверяется офлайн-эталоном пакета 01 — это проверка труб, а не агента.
