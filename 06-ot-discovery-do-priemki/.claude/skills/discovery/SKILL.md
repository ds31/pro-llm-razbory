# Discovery → discovery.yaml

1. Скопировать `templates/discovery.yaml`. Вопросы руководства — дословно из заметок, по одному на строку `questions`; к каждому — `decision`. Вопрос без решения записать в заметки, но не в файл.
2. Роли — в `stakeholders`; имён людей и названий компаний в файл не писать.
3. Карта данных: каждая таблица, из которой считается хоть одно число. Профилирование по `templates/interview.md` (раздел «Профилирование»); каждая находка — строка `issues` с примером «где именно».
4. Для каждого вопроса: метрика из каталога слоя, определение словами владельца, альтернативы, период, разрез и `row_question`, владелец, эталон (`golden.sql` + кто и когда подписал).
5. На каждую проблему источников вопроса и каждую альтернативу — кейс в `checks`: вопрос, на котором наивный запрос ошибается, `metric_query` и `golden_sql`.
6. `uv run razbor06 check <файл>` — пока есть пробелы, выписать их человеку списком «кому какой вопрос задать». Пробел не заполнять догадкой: поле пустое, пока владелец не ответил.
7. Готово — `uv run razbor06 scaffold <файл> -o acceptance.yaml` и показать человеку кейсы на согласование.
