# Приёмка по eval

1. `uv run pytest -q` — зелёный.
2. `uv run razbor06 accept --prototype <prototype.yaml>` — ворота по каждому варианту; отчёт `eval/out/report.md`, сводка `eval/out/summary.json`.
3. Разобрать вердикт по воротам: G1–G2 не пройдены — вернуться в discovery; G3 — чинить слой метрик, не агента; G4 — смотреть трассы ошибочных ответов; G5 — модель, кэш, число шагов.
4. «Ждёт прогона» — вопросы без ответа агента выгружены в `eval/out/agent-root-<вариант>`. Прогон платный: сначала показать человеку число вопросов и оценку цены (средняя цена ответа варианта из сводки × число вопросов), запускать только после его «да»: `uv run razbor01 eval --root eval/out/agent-root-<вариант> --variants <вариант>`.
5. Затем `uv run razbor06 accept --variants <вариант> --results eval/out/agent-root-<вариант>/eval/out/results.jsonl`.
6. Пороги из `prototype.yaml` не менять, чтобы вариант прошёл: порог меняет только владелец числа, новой версией спеки.
