## Что считаем «работает»

| Порог | Значение | Почему такое |
|---|---|---|
| допуск по каждому числу | ±0,5 % | <как договорились с владельцем> |
| кейсы приёмки | все из `razbor06 scaffold`, без TODO | каждая проблема источника и каждая альтернатива проверены |
| ответ агента | на каждый кейс и каждую строку разреза | число, которого агент не давал, не принято |
| средняя цена ответа | ≤ <$> | <бюджет в месяц ÷ число вопросов> |
| среднее время ответа | ≤ <с> | <сколько готовы ждать> |

Пороги после начала работ не меняются. Если владелец хочет их поменять — это новая версия спеки с датой.
