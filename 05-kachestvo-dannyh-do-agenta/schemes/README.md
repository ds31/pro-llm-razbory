# schemes

Исходники схем статьи: `scheme.py` — копия `web/tools/scheme.py` сайта pro-llm.ru (стиль), `schemes_razbor_05.py` — три схемы разбора: ворота перед слоем агента, дефекты и правила, устройство пакета. Перерисовать в эту папку из корня пакета:

```bash
SCHEMES_OUT=schemes python3 schemes/schemes_razbor_05.py
```
