# CLAUDE.md — пакет 05 «Качество данных до агента»

Отвечай по-русски.

## Что это

Эксперимент без LLM: живой поток октября 2026 (файл на магазин за день, снимок остатков на конец месяца, справочник) поверх истории пакета 01 идёт к агенту тремя путями — без ворот (закрытие по календарю), с правилами пакета 01 в слоях (закрытие по снимку остатков) и через ворота (SQL-правила на каждой загрузке, карантин, закрытие месяца по чек-листу). В поток вносятся дефекты с известной правдой; меряется, какую выручку октября каждый путь объявляет окончательной и как отвечает слой метрик пакета 01 на вопросы про «последний месяц». Отдельная команда проверяет то же агентом B пакета 01 через API.

## Команды

- тесты: `uv run pytest -q` (в API не ходят, около трёх минут);
- всё сразу: `uv run razbor05 all` (история, 11 сценариев-витрин, 200 случайных сценариев, отчёт `eval/out/report.html`, около пяти минут на 8 ядрах); быстрее — `-n 20`;
- паспорта правил: `uv run razbor05 rules`;
- один дефект: `uv run razbor05 showcase --defect kopecks` (список — `SHOWCASE` в `src/razbor05/experiment.py`);
- утро за утром в воротах: `uv run razbor05 replay --defect all --until 2026-11-06`;
- чек-лист закрытия на утро: `uv run razbor05 close --defect all --as-of 2026-11-03`;
- агент B пакета 01 на витрине ворот: `uv run razbor05 agent --offline` (без ключа) или с ключом — см. `README.md`.

## Устройство

| Путь | Что |
|---|---|
| `rules/R*.sql`, `rules/C01_*.sql` | правила: паспорт в заголовке, тело — SELECT нарушений |
| `rules/close/K*.sql` | чек-лист закрытия месяца |
| `src/razbor05/feed.py` | история пакета 01, правда и чистый поток загрузок |
| `src/razbor05/defects.py` | дефекты: портят поток, правду не трогают |
| `src/razbor05/rules.py`, `gate.py`, `close.py` | паспорт правил, ворота (stage → правила → core или карантин q), закрытие |
| `src/razbor05/modes.py` | три пути к агенту и правда; витрины и слой метрик — пакета 01 |
| `src/razbor05/questions.py` | девять вопросов про «последний месяц» через `compile_query` пакета 01 |
| `src/razbor05/experiment.py`, `report.py`, `cli.py` | прогон, отчёт, команда |
| `src/razbor05/agent_check.py` | агент B пакета 01: closed_through по календарю против ворот |
| `eval/reference-run.json`, `eval/agent-run.json` | прогоны автора — цифры статьи |

Пакет 01 подключён path-зависимостью (`../01-agent-vret-v-cifrah`): его генератор, `layers.sql`, слой метрик и агент используются без изменений.

## Правила

1. Только синтетические данные; реальные базы, выгрузки и названия компаний не подключать.
2. Правило качества меняется только в своём файле `rules/*.sql` и вместе с тестом (скилл `add-quality-rule`); у каждого правила заполнен паспорт, `why` объясняет «почему», а не «что».
3. Новый дефект — функция в `defects.py`, которая портит поток и не трогает правду; правило должно его поймать, чистый поток — остаться без срабатываний.
4. Месяц закрывают только ворота по чек-листу; `closed_through` в `metrics.yaml` руками не править.
5. Платный прогон (`agent` без `--offline`) — только по просьбе человека, сначала `--only` на одном вопросе.
6. Ключ API — только из окружения; `.env` не читать и не коммитить.
