# data

Только синтетика. `uv run razbor05 data` строит `data/base.duckdb`: история вымышленной розничной сети генератором пакета 01 (seed 43) до 30.09.2026 и справочные цены SKU за сентябрь. Поток октября и правда создаются в памяти на каждый сценарий (seed потока витрины — 46, случайных сценариев — 1000…1199). Файлы баз в git не кладутся.
