# Добавить вопрос eval

1. Сформулировать вопрос так, как его задал бы руководитель: с периодом и единицей ответа («в рублях», «в штуках», «номер магазина»).
2. `check_sql` — эталон по `raw` с правилами компании: `abs(qty) < 1000`, справочник через `(SELECT DISTINCT sku, category, brand FROM raw.products)`, только закрытые месяцы.
3. Ловушка (`dup_join`, `anomaly`, `open_month`, `definition`) — `trap_sql`: запрос, который на ней ошибается. Без ловушки — `trap: none` и без `trap_sql`.
4. Если ответ даёт одна метрика — `metric_query`.
5. `uv run pytest tests/test_golden.py -q`: эталон — число, ловушка промахивается сильнее допуска, слой метрик сходится с эталоном. Шесть вопросов на ловушку сохранять.
