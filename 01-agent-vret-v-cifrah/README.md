# 01 · Почему AI-агент врёт в цифрах — и какая платформа данных это лечит

Рубрика: Платформа под агентом. Статья: https://pro-llm.ru/blog/pochemu-ai-agent-vret-v-cifrah.html

Один и тот же агент на Claude отвечает на 30 бизнес-вопросов о синтетической розничной сети дважды: по сырым таблицам (вариант A) и через витрины и слой метрик (вариант B). Ответы сверяются с эталонами с допуском ±0,5 %. Четыре ловушки — дубли в справочнике, аномальные строки, незакрытый месяц, разные определения метрики — и контрольная шестёрка вопросов без ловушки показывают, где именно агент без платформы ошибается.

## Результат прогона автора

`claude-sonnet-5.5`, 19.10.2026, 30 вопросов × 2 варианта; все ответы — в `eval/reference-run.json`.

| | Верно | Без ловушки | Дубли | Аномалии | Незакрытый месяц | Определения | Цена ответа | Время ответа |
|---|---|---|---|---|---|---|---|---|
| **A** — сырые таблицы | **24 / 30** | 6/6 | 5/6 | 4/6 | 4/6 | 5/6 | $0,026 | 10,0 с |
| **B** — слой метрик | **30 / 30** | 6/6 | 6/6 | 6/6 | 6/6 | 6/6 | $0,016 | 4,9 с |

Как ошибается A: дубли в справочнике и определения он разруливает сам, а все шесть ошибок — из двух правил компании, которых нет в данных. Строки-ошибки сканера (qty = 9999) раздувают выручку в 7,6 и 55 раз и сдвигают две доли (с одним фильтром `abs(qty) < 1000` запросы агента дают ровно эталон); «последний месяц» оказывается десятью днями незакрытого октября — ответ меньше в 2,7–2,9 раза. Весь прогон стоил $1,27.

## Запуск одной командой

```bash
uv run razbor01 all
```

Нужны [uv](https://docs.astral.sh/uv/) и ключ `ANTHROPIC_API_KEY` в окружении. Полный прогон — 60 ответов модели `claude-sonnet-5-5`, около $1,3. Отчёт — `eval/out/report.html`.

Через OpenRouter — те же модели под именами `anthropic/…`:

```bash
export ANTHROPIC_BASE_URL=https://openrouter.ai/api ANTHROPIC_AUTH_TOKEN=<ключ OpenRouter>
uv run razbor01 all --model anthropic/claude-sonnet-5.5
```

Без ключа: `uv run razbor01 all --offline` — проверка конвейера эталонными ответами (это не агент).

Дешёвый пробный прогон: `uv run razbor01 eval --only Q07,Q19 --variants A,B`.

## Что внутри

| Путь | Зачем |
|---|---|
| `src/razbor01/synth.py` | генератор базы DuckDB: 12 магазинов, 200 товаров, 24 закрытых месяца и незакрытый октябрь 2026 |
| `src/razbor01/layers.sql` | правила компании в одном месте: справочник без дублей, без строк-ошибок, только закрытые месяцы |
| `metrics.yaml` | слой метрик: формула, измерения, правило времени, правила R1–R5 |
| `src/razbor01/tools.py`, `guard.py` | инструменты агента A и B и шлюз SQL; база открыта только на чтение |
| `src/razbor01/agent.py` | цикл агента на Claude API: трасса, токены, цена |
| `eval/questions.yaml` | 30 вопросов: эталон `check_sql`, наивный запрос `trap_sql`, запрос к слою метрик |
| `CLAUDE.md`, `.claude/skills/` | контекст и скиллы для Claude Code: добавить метрику, добавить вопрос, разобрать прогон |

## Ловушки

| Ловушка | Что в данных | Как ошибается наивный запрос |
|---|---|---|
| дубли в справочнике | у 10 товаров по две карточки | join размножает строки продаж |
| аномальные строки | 40 строк с qty = 9999 | ошибка сканера попадает в выручку |
| незакрытый месяц | продажи по 10.10.2026, остатков за октябрь нет | «последний месяц» = десять дней октября |
| определение метрики | возвраты, остатки на конец месяца | остатки складываются по месяцам, доля считается не от той базы |

## Как перенести на свои данные

1. Заменить `synth.py` выгрузкой своих таблиц в схему `raw`.
2. Записать свои правила очистки в `layers.sql`, определения — в `metrics.yaml`.
3. Составить 30 своих вопросов с эталонами в `eval/questions.yaml` (скилл `add-eval-question`).
4. Прогнать и сравнить A и B.
