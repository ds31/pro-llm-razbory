# data

Только синтетика. Генератор — `src/razbor08/source.py`: вымышленная розничная сеть, seed 8.

| Объём | Магазинов | Товаров | Дней истории | Строк в документе продаж за день |
|---|---|---|---|---|
| S | 5 | 300 | 365 | 25 |
| M | 20 | 1 000 | 730 | 40 |
| L | 60 | 2 000 | 1 095 | 40 |

История заканчивается 18.10.2026; эксперимент живёт 28 бизнес-дней с 19.10 по 15.11.2026. События каждого дня: продажи всех магазинов, поступления по графику, правки задним числом (документы последних 45 дней), отмена проведения, пометка на удаление, прямое удаление (каждый третий день), поздняя запись (начата до 02:00, зафиксирована после) и две правки справочника товаров.

Команды кладут сюда рабочие файлы: `work/` — прогон `all`, `demo/` и `dwh.duckdb` — демо-хранилище. В git они не попадают.
