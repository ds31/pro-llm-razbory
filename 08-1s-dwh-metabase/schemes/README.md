# schemes

Исходники схем статьи: `scheme.py` — копия `web/tools/scheme.py` сайта pro-llm.ru (стиль), `schemes_razbor_08.py` — три схемы разбора: одна ночь платформы от 1С до агента, устройство пакета, четыре способа загрузки на прогоне автора. Перерисовать в эту папку из корня пакета:

```bash
SCHEMES_OUT=schemes python3 schemes/schemes_razbor_08.py
```
