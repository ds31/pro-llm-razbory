# CLAUDE.md — пакет 08 «Компания на 1С без команды данных»

Отвечай по-русски.

## Что это

Эталонная платформа для компании на 1С без своей команды данных и эксперимент без LLM. Синтетическая информационная база «1С» вымышленной розничной сети (справочники, документы с табличными частями, движения регистра остатков) живёт 28 бизнес-дней с правками задним числом, отменой проведения, пометками на удаление, прямыми удалениями и поздними записями. Каждую ночь в 02:00 она выгружается в файлы обмена четырьмя способами — полная перезагрузка, инкремент по дате документа, «всё после прошлого запуска», дата изменения с перекрытием и воскресной сверкой — в четыре хранилища. Меряется нагрузка на источник (запросы, строки, байты), время и расхождение витрин с эталоном, посчитанным прямо по источнику. Витрины совместимы с пакетом 01: его слой метрик и агент подключаются без правок; Postgres + Metabase — в `deploy/`.

## Команды

- тесты: `uv run pytest -q` (без Docker и без API, около 15 секунд); тест публикации в Postgres — только с `RAZBOR08_PG_DSN`;
- эксперимент: `uv run razbor08 all` (три объёма × 28 ночей, отчёт `eval/out/report.html`); быстро — `uv run razbor08 all --quick` (объём S, 7 ночей);
- демо-хранилище: `uv run razbor08 demo --volume M` → `data/dwh.duckdb`;
- метрика слоя пакета 01: `uv run razbor08 metric revenue --from 2026-10-01 --to 2026-10-31 --by region`;
- Metabase: `docker compose -f deploy/docker-compose.yml up -d`, `uv run --extra pg razbor08 publish`, `python3 deploy/metabase_bootstrap.py`.

## Правила

1. Только синтетические данные. Реальные базы 1С, выгрузки, имена объектов и схемы таблиц заказчиков не подключать; имена объектов в пакете — упрощённые и по смыслу.
2. Данные из 1С — только штатными средствами платформы (расширение, HTTP-сервис, OData, планы обмена). Прямое чтение таблиц СУБД не предлагать: официальный FAQ 1С по лицензированию это запрещает (вопрос X.6-65).
3. Новый объект выгрузки — скилл `add-1c-object`, с тестом на эталон после правки задним числом и удаления.
4. Проверка загрузки отклоняет пакет целиком (K1, K2) или задерживает документ (K3); водяной знак двигается только после принятого пакета.
5. Цифры статьи — только из `eval/reference-run.json`; время зависит от машины, строки и байты — нет.
6. Ключи и пароли — из окружения или `deploy/.env`; `.env` не читать и не коммитить.
