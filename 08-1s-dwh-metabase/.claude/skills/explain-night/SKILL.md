# Разбор ночи

1. Журнал: `SELECT * FROM meta.loads ORDER BY batch_id DESC` в хранилище (`data/dwh.duckdb` после `uv run razbor08 demo`). `status = rejected` — смотреть `checks`: K1 — файл неполный против манифеста, K2 — пустые или повторные ссылки. Водяной знак (`meta.state.last_run`) после отклонённого пакета не двигается — следующая ночь заберёт всё заново.
2. Задержанные документы — `meta.held` (K3: ссылка на товар или магазин, которых нет в справочнике пакета). Назвать документ, ссылку и что исправить в 1С.
3. Расхождение с 1С: сравнить контрольные суммы магазин × месяц (`experiment.reconcile`). Каждую расходящуюся пару объяснить событием: правка задним числом, отмена проведения, пометка на удаление, прямое удаление, поздняя запись.
4. Выбор способа — по таблице в `docs/architecture.md` и прогону `eval/reference-run.json`: что каждый способ видит и сколько читает из 1С за ночь.
5. Цифры объяснения — только из журнала, прогона или запроса к хранилищу; не оценивать на глаз.
