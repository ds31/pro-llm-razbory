# eval

Eval пакета 08 — не вопросы к модели, а сверка витрин с эталоном каждую ночь.

- **Эталон** (`src/razbor08/truth.py`): продажи магазин × день, остаток на последний день и остатки на конец каждого полного месяца, посчитанные прямо по базе-источнику на момент выгрузки — минуя файлы и загрузчик.
- **Что меряется** в каждой из 28 ночей для каждого способа: запросы к источнику (страница — 500 объектов или 5 000 движений), прочитанные строки (объекты справочников и документов, строки табличных частей, движения), байты файлов, время выгрузки, загрузки и витрин; расхождения: магазино-дни продаж, ячейки остатков, магазино-месяцы с ошибкой выручки больше ±0,5 % (допуск eval пакета 01), ошибка выручки сети за последний полный месяц.
- **Способы**: `full` — полная перезагрузка; `doc_date` — документы за последние 3 дня по дате документа; `watermark` — изменённое после прошлого запуска; `safe` — изменённое после прошлого запуска минус 2 часа и сверка контрольных сумм магазин × месяц по воскресеньям с перевыгрузкой расходящихся пар.

## Критерий «прошёл»

1. `full` и `safe` в последнюю ночь (воскресенье, после сверки) совпадают с эталоном: ноль магазино-дней, ячеек остатков и магазино-месяцев с ошибкой.
2. `safe` читает из источника за ночь на порядок меньше `full` на каждом объёме.
3. Отклонённый пакет (K1, K2) не меняет raw и не сдвигает водяной знак — это проверяют тесты.

## Файлы
