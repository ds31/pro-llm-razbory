# 08 · Компания на 1С без команды данных: как дойти до отчётов и AI-аналитика и не положить базу?

Рубрика: Платформа под агентом. Статья: https://pro-llm.ru/blog/1s-bez-komandy-dannyh-ot-vygruzki-do-agenta.html

Эталонная платформа для компании на 1С без своей команды данных — ночная выгрузка, хранилище, Metabase, слой метрик и агент — и эксперимент без LLM. Синтетическая «1С» вымышленной розничной сети живёт 28 бизнес-дней с правками задним числом, отменой проведения, удалениями и поздними записями. Каждую ночь она выгружается в файлы обмена четырьмя способами в четыре хранилища; витрины каждого сверяются с эталоном, посчитанным прямо по источнику. Вы получаете у себя: код выгрузки-загрузки с проверками пакета, docker compose с Postgres и Metabase, настройку дашборда через API и порядок работ по неделям.

## Результат прогона автора

`eval/reference-run.json`, 28 ночей с 19.10.2026, seed 8. Объём L — 60 магазинов, 2 000 товаров, три года истории (75 146 документов, 3 498 880 строк табличных частей):

| Способ | Строк из 1С за ночь | Файлов за ночь | Ночей с расхождением из 28 | Магазино-месяцев с ошибкой > 0,5 % в последнюю ночь |
|---|---|---|---|---|
| полная перезагрузка | 7,2 млн | 1,79 ГБ | 0 | 0 |
| по дате документа, 3 дня | 20,3 тыс. | 5,1 МБ | 28 | 117 |
| после прошлого запуска | 9 815 | 2,4 МБ | 27 | 90 |
| дата изменения − 2 ч + сверка по воскресеньям | 11,7 тыс. | 2,9 МБ | 19 | 0 |

Строк из 1С за ночь на трёх объёмах — полная перезагрузка / перекрытие + сверка: S 126,5 тыс. / 1 365, M 1,6 млн / 4 747, L 7,2 млн / 11,7 тыс.. Время выгрузки и загрузки — в отчёте; оно зависит от машины.

## Запуск одной командой

```bash
uv run razbor08 all
```

Нужен только [uv](https://docs.astral.sh/uv/); ключи API и Docker не нужны. Три объёма по 28 ночей — от получаса и дольше, зависит от машины; проверить конвейер за минуту — `uv run razbor08 all --quick`. Отчёт — `eval/out/report.html`.

Другие команды:

```bash
uv run razbor08 demo --volume M                         # демо-хранилище data/dwh.duckdb
uv run razbor08 metric revenue --from 2026-10-01 --to 2026-10-31 --by region   # слой метрик пакета 01
uv run pytest -q                                        # тесты, без Docker
```

Metabase с дашбордом на демо-хранилище:

```bash
cp deploy/env.example deploy/.env                       # поменять пароли
docker compose -f deploy/docker-compose.yml up -d       # Postgres :5452, Metabase :3030
uv run --extra pg razbor08 publish
python3 deploy/metabase_bootstrap.py
```

## Как перенести на свою 1С

1. Выписать 20–30 вопросов руководства с ответами — список объектов 1С и будущий eval.
2. Сделать расширение, которое отдаёт объекты в формате пакета с манифестом (поля — `src/razbor08/source.py`, `export`); данные — только штатными средствами платформы.
3. Подменить синтетический источник своими файлами, оставить проверки K1–K3 и воскресную сверку.
4. Поднять `deploy/`, опубликовать витрины, собрать дашборды на вопросах шага 1.
5. Дальше — ворота пакета 05 и слой метрик с агентом пакета 01; порядок — `docs/plan-po-nedelyam.md`.
